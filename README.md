# Stream Control (Fabric, Minecraft 1.21.11, только сервер)

Донаты DonationAlerts и голосования чата Twitch запускают команды на сервере. Игрокам ничего ставить не нужно.

## Сборка на GitHub
1. Создай репозиторий и загрузи в него все файлы проекта (вместе с папкой `.github`).
2. Вкладка **Actions** → последний запуск **build** → внизу **Artifacts** → скачай архив.
3. В архиве нужен файл `streamcontrol-1.0.0.jar` (не `-sources`).

## Установка на сервер
Нужны Fabric 1.21.11, **Fabric API** и этот `.jar` в папке `mods`. После первого запуска появится `config/streamcontrol.json`.

## Настройка (config/streamcontrol.json)
- `owners` — ники владельцев (вместо `ВПИШИ_НИК_СТРИМЕРА`), `admins` и `mods` — ники помощников.
- `twitchChannel` — канал Twitch, `donationAlertsToken` — секретный токен DonationAlerts.
- `target` — ник стримера в игре (вместо `{p}` в командах). `@a` — все игроки.
- `rules` — список событий: диапазон суммы `from`–`to`, название и команды через `;;` (`wait 10` — пауза в секундах).
После правок выполни `/stream reload` (из консоли сервера или от владельца).

## Команды `/stream`
- `status`, `rules` — состояние и список событий с номерами (модератор и выше)
- `vote random <сек> <кол-во>`, `vote start <сек> <номера через пробел>`, `vote stop` — голосования (модератор и выше)
- `run <номер>`, `test <сумма>` — запуск события и имитация доната (админ и выше)
- `reload`, `allow <owner|admin|mod> <ник>`, `deny <ник>` — владелец; консоль сервера всегда владелец

Права определяются по нику из конфига. Команды выполняются от имени сервера, оператор (op) не нужен.
